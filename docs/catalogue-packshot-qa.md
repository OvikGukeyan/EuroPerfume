# Catalogue photo checks for full-bottle batches

Check each new primary packshot against the same compact-card frame at desktop
and mobile widths. Use a verified, permitted image of the exact fragrance and
version, preferably a front-facing bottle alone on a neutral background. Match
the visible bottle height and centre it; matching the file dimensions alone is
not sufficient. Retain its proportions and leave room around the cap/base.
Do not replace a bottle with a different volume, concentration or edition just
to fill the frame. Product galleries may retain manufacturer box/view photos.

If an existing file is correctly identified but has larger margins, measure the
non-background bounds, then add a bounded scale for its exact URL origin and
path in catalogue-packshot-scale.ts. Do not infer rules from the brand or
filename. Check the result with a comparison sheet and storefront card sample
at both widths. If the file contains a box, fit the complete packshot and record
that a verified bottle-only replacement is still needed. Do not modify source
bitmaps when a display adjustment is sufficient. Treat legally permitted image
use and source/formula verification as separate checks before publishing new SKUs.
